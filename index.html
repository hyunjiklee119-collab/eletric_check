구글 시트 연동 (Google Apps Script) 설정

작동 원리

구글 스프레드시트의 [확장 프로그램] > [Apps Script]에 아래 스크립트를 붙여넣고 웹 앱으로 배포하면, 여러 개의 기기를 점검하더라도 1회의 제출 시 1개 행(Row)으로 정돈되어 자동 기록됩니다.

배포된 Apps Script 웹 앱 URL 주소를 여기에 입력하고 저장하세요.

설치 및 연동 방법 (3단계):

  1. 새 구글 스프레드시트 생성 후 상단 메뉴 [확장 프로그램] > [Apps Script] 클릭
  2. 기존 코드를 모두 삭제하고, 아래 **[스크립트 코드 복사]** 버튼을 눌러 붙여넣기
  3. 우측 상단 [배포] > [새 배포] 선택 후, 유형: 웹 앱, 액세스 권한: 모든 사용자(Anyone)로 배포 후 URL 복사!
Google Apps Script (Code.gs) 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // 헤더가 없으면 자동 생성
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "제출일시", "점검일자", "점검자", "점검부서", "설치장소", 
        "총기기수", "종합판정", "기기점검 요약데이터", "종합비고"
      ]);
    }
    
    // 행 데이터 준비
    var rowData = [
      data.timestamp || new Date().toLocaleString("ko-KR"),
      data.inspectionDate || "",
      data.inspectorName || "",
      data.inspectionDept || "",
      data.inspectionLocation || "",
      data.totalDeviceCount || 0,
      data.overallStatus || "",
      data.devicesSummaryString || "",
      data.overallRemarks || ""
    ];
    
    // 데이터 저장
    sheet.appendRow(rowData);
    
    return ContentService.createTextOutput(JSON.stringify({ "result": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "result": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
